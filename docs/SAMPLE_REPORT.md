## 중복과 재현

공백·대소문자·제로폭 문자를 정규화하고 고정 알림의 인용 본문을 추출합니다. 동일 본문 또는 100자 이상, 길이 차이 10% 이하, SequenceMatcher 0.94 이상이면 채널을 가로질러 같은 군집으로 묶습니다. 같은 사건의 서로 다른 해설은 별도 군집일 수 있습니다. 전달 표시만으로 중복 처리하지 않습니다. 일별 군집 수는 선택 범위의 첫 등장일에 배정합니다.

전주를 수집하지 않아 증가율은 제공하지 않습니다. verify.py로 합계와 원문 포함 여부를 검사합니다. channels.json은 공통 채널 레지스트리, issues_catalog.json은 이슈 편집 원본입니다. 재생성 순서: collect.py → analyze.py → report.py → verify.py. 이전 3채널 데이터는 snapshots/sample-3channels에 보관했습니다.
